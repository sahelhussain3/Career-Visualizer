# Career Path Visualizer

A responsive web application that helps users discover career paths tailored to their education, interests, and skills. Features AI-powered job suggestions with salary and growth forecasts.

## Features

- Multi-step form to gather user information
- AI-powered job matching algorithm
- Specific role suggestions with descriptions
- Salary comparison charts
- Growth forecast visualization
- Links to job searches on Indeed and LinkedIn

## Live Demo

Visit [career-path-visualizer.surge.sh](https://career-path-visualizer.surge.sh) to try out the application.

## Deployment Options

### Deploy to GitHub Pages

1. Create a GitHub repository for this project
2. Push your code to the repository
3. Run the deploy script:
   ```
   npm run deploy
   ```
4. Your app will be available at: https://[your-github-username].github.io/career-path-visualizer

### Deploy to Surge.sh (Easiest)

1. Build your project:
   ```
   npm run build
   ```
2. Deploy to Surge:
   ```
   npm run deploy:surge
   ```
3. Your app will be available at: https://career-path-visualizer.surge.sh

### Deploy to Netlify

1. Create a Netlify account
2. Connect your GitHub repository
3. Set the build command to `npm run build`
4. Set the publish directory to `build`
5. Deploy!

## Local Development

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
